# Google Maps Platform Evaluation

Use Google Maps Platform only if location, geocoding, or mapping is relevant to the product.

Evaluation questions:
- Does the user journey genuinely require a map?
- Which specific API is needed?
- Are billing, quotas, and API-key restrictions configured?
- Is location permission requested only when necessary?
- Is there a useful fallback if the API is unavailable?

Status: Evaluate relevance before implementation.
