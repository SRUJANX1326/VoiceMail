# Cloud Firestore Data Plan

Use Cloud Firestore only if document-oriented cloud storage fits the application.

## Design notes
- Define collections, document fields, and ownership rules.
- Avoid storing secrets or unnecessary personal data.
- Apply least-privilege security rules.
- Plan retention, deletion, and backup behaviour.
- Test denied reads and writes as well as valid operations.
