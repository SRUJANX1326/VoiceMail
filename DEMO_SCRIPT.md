# 90-Second Demo Script

Use a real, working deployment and a test account. Do not display API keys, OAuth tokens, private messages, or personal contact details.

## 0–10 seconds — The problem
“VoiceMail helps people create and manage communication through a voice-first, AI-assisted workflow.”

## 10–25 seconds — Create a draft
Speak or type a short request for a professional email. Show the generated draft and explain that AI assists with drafting rather than independently deciding to send.

## 25–40 seconds — Refine it
Ask for a tone or wording change. Show the revised message and, if available, the read-aloud experience.

## 40–55 seconds — Safety checkpoint
Show the recipient and draft review. Explicitly confirm the user must approve email sending. Do not simulate a successful send if the API did not confirm it.

## 55–68 seconds — WhatsApp handoff
Prepare a sample message and open WhatsApp. Explain that the user reviews and taps Send in WhatsApp.

## 68–80 seconds — Integrations
Briefly show the configured contact/history or Drive workflow. Only show features that are actually working in the deployed build.

## 80–90 seconds — Engineering and impact
Show the architecture diagram and test/evaluation documentation. State measured results only if you have run the tests.

## Recording checklist

- [ ] Use synthetic names and test accounts.
- [ ] Confirm all integrations work before recording.
- [ ] Hide credentials and personal data.
- [ ] Keep the cursor and narration deliberate.
- [ ] Show at least one real end-to-end workflow.
- [ ] Do not edit the recording in a way that implies unimplemented functionality.
