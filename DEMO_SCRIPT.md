# Demo Script

Prepare a short, reliable demonstration:
1. State the user problem in one sentence.
2. Show the main workflow from input to useful output.
3. Demonstrate one realistic edge case.
4. Explain the architecture and any Google APIs actually integrated.
5. Show a measured result only if it comes from a reproducible test.
6. State current limitations honestly.

Keep a recorded fallback demo in case network access fails.
