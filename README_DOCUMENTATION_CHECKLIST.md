# README Documentation Checklist

A useful project README should explain:
- The problem and target users.
- What the application currently does.
- Technology stack and architecture.
- Prerequisites and exact setup steps.
- Environment variables, using placeholders only.
- How to run tests and build the app.
- Demo screenshots or a verified demo link.
- Known limitations and future work.

Mention Google services only where they are actually used or clearly labelled as planned.
