# Google Cloud Deployment Plan

Consider Google Cloud Run, App Engine, or another appropriate hosting option based on runtime and budget.

Before deployment:
1. Identify runtime, build command, and start command.
2. Configure environment variables and secrets.
3. Add health checks and request timeouts.
4. Restrict service permissions.
5. Deploy to a test environment and verify the main user journey.
6. Record the actual deployment URL only after deployment succeeds.

Status: Plan, not proof of deployment.
