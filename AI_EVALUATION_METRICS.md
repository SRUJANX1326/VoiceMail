# AI Evaluation Metrics

Select metrics that fit the real task rather than optimising for a score alone.

Possible measurements:
- Task success rate on a labelled test set.
- Factuality or answer correctness reviewed against a reference.
- Median and p95 latency.
- Failure and timeout rates.
- User completion rate.
- Cost per successful task.

Record dataset size, test method, baseline, and limitations. Never invent benchmark results.
