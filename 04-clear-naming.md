# Descriptive naming

**Scoring area:** Code Quality (84)

## Why this earns a high score
Names say what code does, which cuts the need for comments.

## Evidence in your project
- `uploadToDrive`, `resolveFile`, `friendlyDriveError`, `findContact`, `saveEmailHistory`, `getEmailHistory`, `spokenFileName`, `normalizeSpokenEmail`, `spellEmail`.
- Constants are named: `FOLDER_NAME`, `MAX_BYTES`, `TYPES`, `SCOPES`, `WAKE`, `BYE`, `YES`, `NO`, `CANCEL`.
- Dialog states read like English: `confirm_recipient`, `confirm_send`, `confirm_upload`, `need_recipient`.

## Takeaway
Self-explanatory identifiers across the backend and dialog logic.
