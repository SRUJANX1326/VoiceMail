# Application Threat Model

Identify assets, trust boundaries, and likely threats.

Consider:
- API-key leakage.
- Unauthorised access to user data.
- Prompt injection in user content or retrieved documents.
- Abuse of external APIs and cost exhaustion.
- Dependency vulnerabilities.
- Sensitive information in logs.

For each threat, document likelihood, impact, mitigation, and how the mitigation is tested.
